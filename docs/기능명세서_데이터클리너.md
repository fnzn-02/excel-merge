# 엑셀 데이터 클리너 - 기능명세서

## 1. 한 줄 정의
하나의 엑셀 파일에 쌓인 지저분한 데이터(중복행, 빈 행/컬럼, 앞뒤 공백 등)를 자동으로 정리해서 다운로드해주는 기능.

## 2. 문제 정의 / 실사용 시나리오
- 하나의 "대장" 파일을 오래 쓰다 보면 중간중간 완전히 빈 행이 끼어있어서 정렬/필터가 이상하게 동작하는 경우
- 여러 사람이 나눠서 입력하다 보니 "홍길동"과 "홍길동 "(뒤에 공백)처럼 같은 값인데 다르게 취급되어 집계(피벗, VLOOKUP 등)가 안 맞는 경우
- 실수로 같은 행을 두 번 입력한 경우
- 다른 시스템에서 내보내기(export)하면서 생긴, 값이 하나도 없는 빈 컬럼들이 지저분하게 남아있는 경우
- "엑셀 병합"과 다르게, **파일이 여러 개가 아니라 하나뿐**이어도 정리가 필요한 상황을 위한 기능 (병합기의 중복제거/빈컬럼제거 기능을 단일 파일에도 쓸 수 있게 독립시킨 버전)

## 3. 타겟 유저
- 엑셀 병합기/분할기와 동일한 타겟 (사무직, 자영업자, 정산 담당자)
- 특히 하나의 마스터 시트를 오래 관리하며 데이터가 누적되는 사람

## 4. 핵심 기능 (체크박스로 각각 켜고 끌 수 있음, 기본값은 전부 켜짐)

1. **완전히 동일한 행 중복 제거** — 병합기에 이미 있는 로직 재사용
2. **완전히 빈 컬럼 제거** — 병합기에 이미 있는 로직 재사용
3. **완전히 빈 행 제거** (신규) — 모든 셀이 비어있는 행 삭제. 중복 제거와 다름(중복은 "똑같은 내용의 행"을 지우고, 이건 "내용이 아예 없는 행"을 지움)
4. **셀 앞뒤 공백 자동 제거(트리밍)** (신규) — 텍스트 셀의 맨 앞/맨 뒤 공백만 제거 (셀 중간의 공백은 건드리지 않음). 숫자/날짜 셀은 그대로 둠

## 5. 입출력
- **입력**: .xlsx, .xls, .csv 파일 1개 (기존 `parseFile` 재사용)
- **출력**: 정리된 결과를 미리보기 + `.xlsx` 다운로드 (병합기와 동일한 다운로드 UX, 파일명 직접 지정 가능)

## 6. UI/UX 흐름
1. 파일 업로드 (분할기와 동일하게 파일 1개만)
2. 4개 체크박스 (기본 전체 체크): 중복행 제거 / 빈 컬럼 제거 / 빈 행 제거 / 공백 트리밍
3. 미리보기 테이블 (병합기와 동일한 스타일) + "총 N행 · M열 · 중복 X행 제거됨 · 빈행 Y개 제거됨" 같은 요약 텍스트
4. 파일명 입력 후 다운로드 버튼

## 7. 제한사항
- 병합기/분할기와 동일하게 10,000행까지 (무료)

## 8. 엣지 케이스
- 체크박스를 전부 꺼도 원본 그대로 보여주고 다운로드 가능 (에러 아님, "정리할 게 없어요" 같은 문구도 필요 없음 — 그냥 원본 그대로 동작)
- 트리밍 결과 완전히 빈 문자열이 된 셀(원래 공백만 있던 셀)은 "빈 행 제거" 판단 시 빈 셀로 취급 (트리밍을 먼저 적용한 다음 빈 행 여부를 판단하는 순서로 처리)
- 헤더 자체에 중복된 이름이 있는 경우는 기존 `parseFile`의 `dedupeHeaders`가 이미 처리하므로 별도 처리 불필요

## 9. 기술 구현 메모
- 새 로직 위치: `lib/clean.ts` (병합/분할과 대칭되는 위치)
- 중복행 제거, 빈 컬럼 제거는 기존 `mergeParsedFiles`에 파일 1개만 넣어서 그대로 재사용 가능 (헤더 유니온 로직은 파일이 1개면 자기 자신의 헤더 순서 그대로 나오므로 부작용 없음)
- 신규 로직만 추가 구현: `removeEmptyRows(rows)`, `trimCells(rows)`
- 처리 순서: 트리밍 → 빈 행 제거 → 빈 컬럼 제거 → 중복행 제거 (트리밍을 제일 먼저 해야 나머지 판단이 정확해짐)
- 라우트: `/excel/clean` 신설, 홈 화면 세 번째 카드로 추가, 이 시점에 홈 그리드를 2열 → 3열로 전환

## 10. 검증 계획
- 실제로 공백 섞인 이름 데이터, 빈 행이 중간에 낀 데이터로 직접 테스트
- 트리밍 전/후로 "빈 행 제거" 판단이 달라지는 경우(공백만 있던 셀)를 별도로 테스트
- 기존 병합기 회귀 테스트 (mergeParsedFiles 재사용하는 부분이 병합 기능에 영향 없는지)
