# 엑셀 분할 - 기능명세서

## 1. 한 줄 정의
하나의 엑셀 파일을 기준에 따라 여러 개의 파일로 나눠서 다운로드해주는 기능. "엑셀 병합"의 반대 동작.

## 2. 문제 정의 / 실사용 시나리오
- 특정 시스템(예: 정부 지원사업 신청, 쇼핑몰 대량등록 등)에 "파일당 최대 OOO행까지만 업로드 가능"이라는 제약이 있어서, 큰 파일을 손으로 잘라야 하는 경우
- 지점별/담당자별/부서별로 나눠서 각자에게 따로 전달해야 하는 경우 (예: "지점"별로 갈라서 각 지점 담당자에게 자기 지점 데이터만 보내야 함)
- 여러 사람이 나눠서 작업하도록 인원수만큼 균등하게 쪼개야 하는 경우
- 지금 병합기 사용자 중 "반대로도 되나요?" 물어볼 가능성이 높은, 자연스러운 짝 기능

## 3. 타겟 유저
- 기존 "엑셀 병합" 사용자와 동일 (사무직, 자영업자, 정산 업무 담당자)
- 특히 "한 파일을 나눠서 여러 곳에 배포해야 하는" 업무를 반복하는 사람

## 4. 분할 기준 (핵심 기능 — 3가지 모드 제공)

### 모드 A: 행 개수 기준
- 사용자가 "한 파일당 몇 행씩 나눌지" 숫자를 입력 (예: 500행씩)
- 헤더는 모든 분할 파일에 동일하게 포함
- 마지막 파일은 나머지 행만큼만 포함 (나누어떨어지지 않아도 됨)

### 모드 B: 특정 컬럼 값 기준
- 사용자가 컬럼 하나 선택 (예: "지점")
- 그 컬럼의 고유값마다 파일 하나씩 생성 (예: "강남점.xlsx", "홍대점.xlsx"...)
- 값이 비어있는 행은 별도로 "미분류.xlsx"에 모음

### 모드 C: 균등 분할 (인원수 기준)
- 사용자가 "몇 개로 나눌지" 숫자만 입력 (예: 3명이 나눠 할 거라 3개로)
- 전체 행수를 그 개수로 최대한 균등하게 나눔 (나머지는 앞쪽 파일에 1행씩 배분)

## 5. 입출력

**입력**: .xlsx, .xls, .csv (기존 병합기와 동일 파서 재사용, `lib/excel.ts`의 `parseFile`)

**출력**: 분할된 파일이 2개 이상이면 **ZIP으로 묶어서 한 번에 다운로드** (개별 다운로드는 파일 많아지면 사용성이 나빠짐 — 브라우저 다운로드 팝업이 파일 개수만큼 뜨는 것 방지)
- ZIP 생성은 클라이언트에서 처리 (`jszip` 라이브러리 추가 필요, 서버 불필요)

## 6. UI/UX 흐름
1. 파일 업로드 (드래그앤드롭, 기존과 동일한 컴포넌트 스타일)
2. 분할 기준 선택: [행 개수] / [컬럼 값] / [균등 분할] 라디오 버튼 또는 탭
   - 행 개수 선택 시: 숫자 입력창
   - 컬럼 값 선택 시: 드롭다운으로 업로드된 파일의 헤더 목록 표시, 그 중 하나 선택
   - 균등 분할 선택 시: "몇 개로 나눌지" 숫자 입력창
3. 미리보기: "총 N개 파일로 분할됩니다" + 각 파일명과 행 수 미리보기 리스트
4. 다운로드 버튼 → ZIP 파일 다운로드

## 7. 제한사항 (무료 플랜 기준)
- 병합기와 동일하게 파일당 10,000행까지
- 컬럼 값 기준 분할 시, 고유값 개수가 너무 많으면(예: 100개 초과) 파일이 100개 넘게 생겨서 비현실적 — 고유값 50개 초과 시 경고 문구 표시 ("분할 결과가 50개를 초과해요. 정말 진행할까요?")

## 8. 엣지 케이스
- 업로드 파일이 헤더만 있고 데이터가 0행인 경우 → 분할 자체가 불필요하다는 안내 문구
- 컬럼 값 기준인데 선택한 컬럼에 값이 전부 동일한 경우 → 파일이 1개만 생성됨(정상 동작, 에러 아님)
- 행 개수 기준인데 입력한 숫자가 전체 행수보다 큰 경우 → 파일 1개만 생성(전체가 그대로 나옴), 에러 대신 자연스럽게 처리

## 9. 기술 구현 메모
- 파싱/헤더 처리: 기존 `lib/excel.ts`의 `parseFile` 그대로 재사용
- 새 로직: `splitByRowCount`, `splitByColumnValue`, `splitEvenly` 함수 추가 (병합 로직과 대칭되는 위치에 작성)
- ZIP 압축: `jszip` 신규 의존성 추가 (무료, 클라이언트 전용, 서버 비용 없음)
- 라우트: `/excel/split` 신설, 홈 화면 카드 목록에 두 번째 카드로 추가, 네비게이션 "엑셀" 드롭다운에도 항목 추가

## 10. 검증 계획
- MVP 완성 후, 이전에 병합기 테스트해준 실사용자(인선님)에게 실제 업무 시나리오로 먼저 테스트 요청
- 특히 "컬럼 값 기준 분할"이 실무에서 제일 많이 쓰일 것으로 예상되므로, 이 모드부터 우선 검증
