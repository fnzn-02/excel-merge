# 엑셀 병합기

여러 개로 흩어진 엑셀(.xlsx, .xls) 및 CSV 파일을 업로드하면 자동으로 헤더를 인식하여 하나의 파일로 병합해 주는 웹 서비스입니다.

**서비스 바로가기:** https://excel-merge-kappa.vercel.app

## 주요 기능

- **다중 파일 업로드:** 드래그 앤 드롭으로 여러 파일 업로드 가능 (파일 개수 무제한, 파일당 최대 3,000행)
- **자동 헤더 인식:** 파일마다 컬럼 순서와 이름이 달라도 자동으로 인식하여 병합
- **중복 데이터 제거:** 완전히 동일한 행 자동 제거 (옵션)
- **빈 컬럼 제거:** 데이터가 없는 컬럼 자동 제거 (옵션)
- **병합 결과 미리보기:** 결과 확인 후 원하는 파일명으로 `.xlsx` 다운로드

## 보안 및 데이터 처리

파일은 서버로 전송되지 않고 **사용자의 브라우저 내부에서만 처리**됩니다.

따라서 회사 및 개인 데이터가 외부 서버로 전송되지 않는 방식으로 동작합니다.

## 기술 스택

| 기술 | 용도 |
|---|---|
| Next.js (App Router) | 웹 애플리케이션 개발 |
| SheetJS (xlsx) | 브라우저 내 엑셀 파싱 및 병합 |
| Tailwind CSS | UI 스타일링 |
| Vercel | 서비스 배포 |

## 로컬 개발 환경 실행

### 1. 저장소 복제

```bash
git clone 저장소주소
cd excel-merge
```

### 2. 패키지 설치

```bash
npm install
```

### 3. 개발 서버 실행

```bash
npm run dev
```

### 4. 브라우저 접속

http://localhost:3000
